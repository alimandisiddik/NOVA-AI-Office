# Roadmap

## Sprint 1.1 — Project Foundation

Establish the repository structure, baseline configuration, documentation, and governance boundaries.

## Recommended next sprint — Sprint 1.2: Core Domain and Agent Contracts

- Define a minimal internal task and approval domain model.
- Specify agent input/output contracts and lifecycle states.
- Add configuration loading and structured logging abstractions.
- Establish test conventions and initial contract tests.
- Keep cloud integrations and AI provider calls out of scope while the local Telegram bot remains intentionally minimal.

## Future milestones

### Agent orchestration

Introduce deterministic workflow routing, state transitions, retries, human approval checkpoints, and audit events.

### Knowledge governance

Establish source registration, ownership, access classification, refresh policies, and retrieval interfaces.

### Integration adapters

Introduce external systems one adapter at a time after security review, consent design, and test coverage.

### Executive experience

Deliver decision briefs, task coordination views, reporting, and approval workflows for executive users.
